═══════════════════════════════════════════════════════════════════════════
                            SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════

🔒 CSRF Protection
   └─ Random state parameter generated and validated
   └─ State stored in httpOnly cookie
   └─ State deleted after use

🔒 Token Security
   └─ Tokens stored in Clerk privateMetadata (encrypted)
   └─ Tokens stored in PostgreSQL
   └─ Never exposed in URLs or client-side code

🔒 Cookie Security
   └─ httpOnly: true (prevents XSS)
   └─ secure: true in production (HTTPS only)
   └─ sameSite: lax (CSRF protection)

🔒 Error Handling
   └─ No sensitive data in error messages
   └─ Safe redirects on failures
   └─ Graceful degradation


═══════════════════════════════════════════════════════════════════════════
                              TIMING BREAKDOWN
═══════════════════════════════════════════════════════════════════════════

Step 1: User clicks "Connect"                    → Instant
Step 2: Consent screen loads                     → < 100ms
Step 3: OAuth initiation                         → < 100ms
Step 4: Redirect to GitHub                       → < 200ms
Step 5: User authorizes (manual)                 → 5-30 seconds
Step 6: GitHub redirects back                    → < 200ms
Step 7: Token exchange                           → 300-500ms
Step 8: Fetch user info                          → 200-400ms
Step 9: Store in Clerk                           → 300-800ms
Step 10: Store in PostgreSQL                     → 50-200ms
Step 11: Redirect to dashboard                   → < 100ms
Step 12: Modal closes                            → Instant

Total (excluding user action): 1.5-2.5 seconds


═══════════════════════════════════════════════════════════════════════════
                            ERROR SCENARIOS
═══════════════════════════════════════════════════════════════════════════

❌ missing_code_or_state
   → GitHub didn't return required parameters
   → Redirect to /connect-github?error=missing_code_or_state

❌ invalid_oauth_state
   → State mismatch (possible CSRF attack)
   → Redirect to /connect-github?error=invalid_oauth_state

❌ missing_oauth_config
   → Client ID or Secret not configured
   → Redirect to /connect-github?error=missing_oauth_config

❌ token_exchange_failed
   → GitHub API error during token exchange
   → Redirect to /connect-github?error=token_exchange_failed

❌ metadata_persist_failed
   → Clerk update failed
   → Redirect to /connect-github?error=metadata_persist_failed

❌ insforge_persist_failed
   → PostgreSQL insert failed
   → Redirect to /connect-github?error=insforge_persist_failed

                          USING THE ACCESS TOKEN
═══════════════════════════════════════════════════════════════════════════

// Fetch token from Clerk
const { userId } = auth()
const user = await clerkClient.users.getUser(userId)
const token = user.privateMetadata.gitguardGithub?.accessToken

// Use with GitHub API
const response = await fetch("https://api.github.com/user/repos", {
  headers: {
    Authorization: `Bearer ${token}`,
    Accept: "application/vnd.github+json",
    "X-GitHub-Api-Version": "2022-11-28"
  }
})

const repos = await response.json()
