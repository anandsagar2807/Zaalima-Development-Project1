# Contributing to GitGuard AI

Thanks for contributing!

## Development setup
1. Install Node.js 18+
2. `npm install`
3. Run:
   - Backend: `npm run dev:backend`
   - Frontend: `npm run dev`

## Branches
- `main`: stable
- `feature-development`: active development

## Commit messages
Use clear, action-oriented messages, for example:
- `feat: add PR diff preprocessing`
- `fix: handle missing GitHub token`
- `docs: update quick start`

## Pull requests
- Keep PRs focused
- Add screenshots for UI changes
- Include a short test plan

## Code style
- Prefer TypeScript
- Run lint/typecheck/tests (if present) before pushing
